Ce que fait ce package

Authentification itsme® via OpenID Connect 1.0 pour Laravel 12 et 13 : PKCE, validation JWT, JWKS, événements et bouton Blade.

OpenID Connect 1.0

Flux complet « authorization code ».

PKCE

Activé par défaut.

Validation JWT

Signature, expiration, audience, émetteur, nonce.

Auto-découverte

Configuration OpenID et clés JWKS récupérées automatiquement.

Middleware et événements

itsme.auth, ItsmeUserCreated, ItsmeUserAuthenticated, ItsmeAuthenticationFailed.

Bouton et i18n

Bouton Blade en 3 tailles, traductions FR/EN.

Installation

Le package n'est pas encore publié sur Packagist : on l'installe depuis le dépôt GitHub.

  1. Ajoute le dépôt et installe le package :
    composer config repositories.itsme-laravel vcs https://github.com/martin-lechene/itsme-laravel
composer require martin-lechene/itsme-laravel:dev-main
  2. Ensuite :
    php artisan vendor:publish --tag=itsme-config
php artisan vendor:publish --tag=itsme-migrations
php artisan migrate
  3. Ensuite :
    php artisan itsme:test-config
